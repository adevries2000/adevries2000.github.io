DairyVIP (dairy value iteration program)

Evaluation of consequences of changes in herd management and prices on dairy farms. This program has monthly time steps, seasonality, and dynamic programming.

Save the .exe (executable) and .xlsm (spreadsheet) files in the same directory and enable macros.

  • Hashtag: dairyvip
  • Developer: A. De Vries
  • Tool: dairyvip21.exe and DairyVIP21.xlsm
  • Documentation: The DairyVIP Program
  • Last updated: June 16, 2016
